## 分类

| 文件夹 | 内容 |
|---|---|
| [移植项目](ports/README.md) | 游戏移植项目和来源目录 |
| [Android](android/README.md) | 经项目作者确认的 Android 移植版和版本 |
| [PC](pc/README.md) | 经项目作者确认的 PC 移植版和版本 |
| [Web](web/README.md) | 经过筛选的浏览器游戏和移植项目列表 |
| [按主机分类的数据](game-data/README.md) | Xbox、Xbox 360、PlayStation、Nintendo 等系统的已核实要求 |

## 浏览项目

[西班牙语主页](README.md)提供已核实的 PC 和 Android 移植项目、筛选后的 Web 游戏列表、按主机整理的数据要求，以及 PortsDR 来源目录。

## 目录原则

- 只有在项目 README 或文档确认后，才按**目标平台**分类。支持多个目标平台的项目可以出现在多个分类中。
- 保留游戏原始平台和项目名称作为元数据；不根据名称猜测目标平台或所需数据格式。
- 链接指向原始项目和文档。本仓库不分发游戏、光盘镜像、ROM、BIOS、密钥或其他受保护资源。
- 请查看作者文档，了解要求、许可证、状态和所需文件。
