# Cómo contribuir

Queremos que el catálogo sea fácil de recorrer, verificable y respetuoso con cada proyecto enlazado.

## Proponer un proyecto

Incluye el juego y su plataforma original, el nombre del proyecto y un enlace a su repositorio o documentación oficial. Indica Android, PC, Web u otro destino solo cuando el soporte esté confirmado por el propio autor (README, documentación o releases). Un proyecto compatible con varios destinos puede aparecer en más de una lista. Si se trata de un fork, explica la diferencia y no lo presentes como el proyecto original.

## Registrar requisitos de datos

Añade una fila a [Datos por consola](game-data/README.md) cuando la fuente del autor confirme los datos necesarios. Distingue imagen de disco (incluido el formato exacto, no solo “ISO”), ROM y assets extraídos. Conserva región/revisión y modo/tamaño de sector si se mencionan. Enlaza la sección exacta del README/documentación y usa “no verificado” si no hay evidencia. No deduzcas el tipo de archivo por consola, nombre del proyecto o formato habitual.

## Proponer un port para Web

Incluye el enlace a la página del juego y a su proyecto o autor cuando estén disponibles. Solo añade juegos oficiales; excluye fangames, romhacks y compendios. Indica claramente la fuente del enlace y no presentes un port como autorizado por el titular si no hay evidencia.

## Calidad y seguridad

- Verifica cada enlace y conserva la atribución a la fuente que lo reportó.
- No alojes ni enlaces a copias no autorizadas de juegos, imágenes de disco, ROMs, BIOS, claves o assets protegidos.
- No declares compatibilidad, licencia, estado de desarrollo, requisitos u oficialidad sin una fuente comprobable.
- Mantén las entradas breves y consistentes; evita duplicados salvo que un mismo proyecto deba aparecer en varias plataformas de destino.
- Al añadir o mover proyectos, actualiza los índices correspondientes.
