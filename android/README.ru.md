# Порты для Android

Проекты, версия для Android которых подтверждена README или документацией репозитория. Если проект также поддерживает ПК или другую платформу, он может присутствовать в нескольких категориях.

[Español](README.md) · [English](README.en.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · [Français](README.fr.md)

## Проверенные порты

| Игра (исходная платформа) | Проект | Данные игры, указанные проектом |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-Android-Port](https://github.com/zwaetschge/ACGC-Android-Port) | Образ USA GAFE01 Rev 0: `.iso`, `.gcm`, `.ciso` или `.nkit.iso`. |
| Crash Team Racing (PlayStation) | [CTR Native Android](https://github.com/Simon358/ctr-native-android) | Оригинальный raw BIN NTSC-U `ctr-u.bin`; `BIGFILE.BIG` и другие извлечённые ресурсы поддерживаются как замена. |

Требования, лицензии, состояние и релизы смотрите в README исходных проектов. Также см. [требования к данным игр](../game-data/README.ru.md) и [исходный каталог PortsDR](../ports/README.ru.md).
