# Android 移植项目

此处收录的项目均由仓库 README 或文档确认支持 Android。同一项目若也支持 PC 或其他目标平台，可以同时出现在多个分类中。

## 已核实的移植项目

| 游戏（原始平台） | 项目 | 项目注明的游戏数据 |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-Android-Port](https://github.com/zwaetschge/ACGC-Android-Port) | USA GAFE01 Rev 0 镜像：`.iso`、`.gcm`、`.ciso` 或 `.nkit.iso`。 |
| Crash Team Racing (PlayStation) | [CTR Native Android](https://github.com/Simon358/ctr-native-android) | 零售版 NTSC-U 原始 BIN `ctr-u.bin`；支持使用 `BIGFILE.BIG` 和其他已提取资源进行覆盖。 |

请查阅原项目 README，了解要求、许可证、状态和发布版本。另请参阅[游戏数据要求](../game-data/README.zh-CN.md)和 [PortsDR 来源目录](../ports/README.zh-CN.md)。
