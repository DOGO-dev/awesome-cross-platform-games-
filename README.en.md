## Catalog guidelines

- We classify by **target platform** only when confirmed in the project's README or documentation. A project supporting multiple targets may appear in more than one section.
- The original platform and project name are retained as metadata; they are not used to guess target or required data formats.
- Links point to original projects and documentation. This repository does not distribute games, disc images, ROMs, BIOS files, keys, or protected assets.
- Always check the author's documentation for requirements, license, status, and required files.
