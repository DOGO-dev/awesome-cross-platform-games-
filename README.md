## Ports confirmados por destino

Enlaces directos a proyectos cuyo destino se verificó en la documentación oficial. La lista completa de [ports para PC](pc/README.md) y sus requisitos está disponible en su categoría; aquí se muestran ejemplos seleccionados.

### PC

| Juego (plataforma original) | Proyecto | Datos del juego requeridos |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-PC-Port](https://github.com/flyngmt/ACGC-PC-Port) | Imagen del disco USA GAFE01 Rev 0: `.iso`, `.gcm` o `.ciso`. |
| Crash Team Racing (PlayStation) | [CTR Native](https://github.com/CTR-tools/ctr-native) | Imagen retail NTSC-U en BIN crudo PSX de una pista, MODE2/2352; no sirve un ISO cocido de 2048 bytes. Admite assets extraídos para desarrollo/modding. |

### Android

| Juego (plataforma original) | Proyecto | Datos del juego requeridos |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-Android-Port](https://github.com/zwaetschge/ACGC-Android-Port) | Imagen del disco USA GAFE01 Rev 0: `.iso`, `.gcm`, `.ciso` o `.nkit.iso`. |
| Crash Team Racing (PlayStation) | [CTR Native Android](https://github.com/Simon358/ctr-native-android) | BIN crudo retail NTSC-U `ctr-u.bin`; también permite `BIGFILE.BIG` y otros assets extraídos. |

### Web

Consulta la [lista de juegos y ports web](web/README.md). Se excluyeron las entradas que la fuente marca como fangames, romhacks o compendios; la legitimidad y los requisitos de cada port deben comprobarse en su página de origen.

## Datos de juego, ISO y otros formatos

No todo requisito es un ISO: Xbox, Xbox 360, PS4 y otros sistemas pueden requerir formatos diferentes según el proyecto. Consulta [Datos por consola](game-data/README.md) para buscar por sistema y comprobar el formato exacto, región/revisión y fuente verificada.

El repositorio enlaza requisitos; no almacena ni distribuye juegos, ISO, ROMs, BIOS, claves ni assets protegidos. Obtén únicamente copias legales y sigue la documentación oficial.

## Criterios

- Clasificamos por **plataforma de destino** solo si el README, documentación o release oficial lo confirma. Un proyecto multiplataforma puede aparecer en más de una lista.
- Registramos plataforma original, formato de datos, región y revisión solo con una fuente verificable.
- Consulta el proyecto original para conocer requisitos, licencia, estado y archivos necesarios.
