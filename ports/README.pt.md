# Ports

Catálogo de projetos de portabilidade de jogos e seus dados de origem. O [índice completo do PortsDR](portsdr-projects.md) preserva 275 repositórios e suas plataformas originais; os destinos e requisitos de mídia ainda precisam ser verificados projeto por projeto.

Use a página principal para ver links diretos dos projetos com destino confirmado. Consulte [requisitos de dados dos jogos](../game-data/README.pt.md) para imagens, ROMs e assets verificados. Navegue por destino: [Android](../android/README.pt.md), [PC](../pc/README.pt.md) e [Web](../web/README.pt.md).
