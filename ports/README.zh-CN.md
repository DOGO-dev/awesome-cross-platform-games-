# 移植项目

此目录整理游戏移植项目及其来源数据。[PortsDR 完整索引](portsdr-projects.md)保留了 275 个仓库及其原始平台；目标平台和媒体要求尚待逐个核实。

请通过主页查看目标平台已确认项目的直达链接。已核实的光盘镜像、ROM 和资源要求请参阅[游戏数据要求](../game-data/README.zh-CN.md)。按目标平台浏览：[Android](../android/README.zh-CN.md)、[PC](../pc/README.zh-CN.md) 和 [Web](../web/README.zh-CN.md)。
