Catálogo de proyectos de porting y sus datos de origen. El [índice completo de PortsDR](portsdr-projects.md) conserva 275 repositorios y sus plataformas originales; todavía no indica destinos ni requisitos de medios porque deben comprobarse proyecto por proyecto.

Usa la portada para ver enlaces directos a los proyectos con destino confirmado y consulta [Requisitos de datos del juego](../game-data/README.md) para ISO/imágenes, ROMs y assets confirmados. Las listas por destino son [Android](../android/README.md), [PC](../pc/README.md) y [Web](../web/README.md).
