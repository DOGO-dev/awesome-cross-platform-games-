# Порты

Каталог проектов по переносу игр и исходных данных. [Полный индекс PortsDR](portsdr-projects.md) содержит 275 репозиториев и их исходные платформы; целевые платформы и требования к носителям ещё необходимо проверять для каждого проекта.

На главной странице размещены прямые ссылки на проекты с подтверждёнными целевыми платформами. См. [требования к данным игр](../game-data/README.ru.md) для проверенных образов дисков, ROM и ресурсов. Просмотр по целям: [Android](../android/README.ru.md), [ПК](../pc/README.ru.md) и [Веб](../web/README.ru.md).
