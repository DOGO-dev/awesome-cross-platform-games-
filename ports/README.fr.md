# Ports

Catalogue de projets de portage de jeux et de leurs données sources. L'[index complet PortsDR](portsdr-projects.md) conserve 275 dépôts et leurs plateformes d'origine ; les plateformes cibles et les besoins en supports restent à vérifier projet par projet.

La page principale fournit des liens directs vers les projets dont la plateforme cible est confirmée. Consultez les [besoins en données de jeu](../game-data/README.fr.md) pour les images disque, ROM et ressources vérifiées. Parcourez par cible : [Android](../android/README.fr.md), [PC](../pc/README.fr.md) et [Web](../web/README.fr.md).
