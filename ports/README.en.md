# Ports

Catalog of game-porting projects and their source data. The [complete PortsDR index](portsdr-projects.md) preserves 275 repositories and their original platforms; target platforms and media requirements have not yet been checked project by project.

Use the main page for direct links to projects with confirmed target platforms. See [game data requirements](../game-data/README.en.md) for verified disc images, ROMs, and assets. Browse projects by target: [Android](../android/README.en.md), [PC](../pc/README.en.md), and [Web](../web/README.en.md).
