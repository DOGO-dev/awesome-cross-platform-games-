# Порты для ПК

Проекты с поддержкой ПК или версией для ПК, подтверждённой README или документацией репозитория. Мультиплатформенный проект также может присутствовать в разделах [Android](../android/README.ru.md) или [Веб](../web/README.ru.md).

## Проверенные порты

| Игра (исходная платформа) | Проект | Данные игры, указанные проектом |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-PC-Port](https://github.com/flyngmt/ACGC-PC-Port) | Образ USA GAFE01 Rev 0: `.iso`, `.gcm` или `.ciso`. |
| Crash Team Racing (PlayStation) | [CTR Native](https://github.com/CTR-tools/ctr-native) | Оригинальный однодорожечный PSX raw BIN NTSC-U, MODE2/2352; ISO с секторами по 2048 байт не подойдёт. Извлечённые ресурсы необязательны для разработки/моддинга. |
| 3 on 3 NHL Arcade (Xbox 360) | [3on3NHL-recomp](https://github.com/Wndwsqrrl/3on3NHL-recomp) | Собственный пакет Xbox Live Arcade, Title ID `58410975`; ISO не требуется. |
| Call of Duty: Finest Hour (Xbox) | [FinestHourRemastered](https://github.com/crazyriddler/FinestHourRemastered) | Совместимый образ Xbox: `.iso`, полный образ Redump или XISO. |
| Glover (Nintendo 64) | [Glover-R](https://github.com/ThatGuyMcd/Glover-R) | ROM USA для Nintendo 64; поддерживаются `.z64`, `.n64` и `.v64`. |
| Go! Go! Ackman (SNES) | [gogoackman1recomp](https://github.com/catmidori/gogoackman1recomp) | ROM/dump SNES; точный формат не указан. |
| Kameo: Elements of Power (Xbox 360) | [KameoRePowered](https://github.com/MaxDeadBear/KameoRePowered) | Собственный ISO-образ Xbox 360 (`kameo.iso`). |
| Lost Odyssey (Xbox 360) | [LostOdysseyRecomp](https://github.com/faligame/lost-odyssey-hd-remaster) | Четыре диска; поддерживаются извлечённые папки, ISO или данные Games on Demand. Для запуска нужен диск 1. |
| Naruto: The Broken Bond (Xbox 360) | [Naruto-The-Broken-Bond-PC-Port](https://github.com/Auremana666/Naruto-The-Broken-Bond-PC-Port) | Собственный ISO-образ Xbox 360. README упоминает исполняемый файл Windows; его работу независимо не проверяли. |
| Pandora's Tower (Wii) | [pandora-tower-pc](https://github.com/RecompPort/pandora-tower-pc) | Собственный ISO-образ Wii; согласно PortIntegration, перекомпиляция выполняется при установке. |
| Ridge Racer V (PlayStation 2) | [Fukami](https://github.com/danisandoval/fukami) | Дамп американской версии PS2 (SLUS-20002); расширение файла не указано. |
| Scooby-Doo! Night of 100 Frights (GameCube) | [Scooby-Doo-Refrightened](https://github.com/josiahg2502-glitch/Scooby-Doo-Refrightened) | ISO USA для GameCube v1.01 (GIHE78, ревизия 1). |
| Sonic Mania (официальные ресурсы) | [Sonic-Mania-Decompilation](https://github.com/RSDKModding/Sonic-Mania-Decompilation) | Нужны ресурсы совместимого официального издания; ISO/ROM не требуется. |
| Sonic the Hedgehog 1 & 2 (2013) | [RSDKv4-Decompilation](https://github.com/RSDKModding/RSDKv4-Decompilation) | Нужны ресурсы совместимого официального издания (Steam, Epic или Nintendo Switch); ISO/ROM не требуется. |
| Sonic the Hedgehog CD (2011) | [RSDKv3-Decompilation](https://github.com/RSDKModding/RSDKv3-Decompilation) | Нужны ресурсы совместимого официального издания; ISO/ROM не требуется. |
| Super Paper Mario (Wii) | [NewSuperPaperBros](https://github.com/josiahg2502-glitch/NewSuperPaperBros) | Дамп/образ собственного диска Wii; точный формат не указан. |

Требования, лицензии, состояние и релизы смотрите в README исходных проектов. Также см. [требования к данным игр](../game-data/README.ru.md) и [исходный каталог PortsDR](../ports/README.ru.md).
