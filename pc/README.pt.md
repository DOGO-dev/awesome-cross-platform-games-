# Ports para PC

Projetos cuja compatibilidade ou versão para PC é confirmada pelo README ou pela documentação do repositório. Um projeto multiplataforma também pode aparecer em [Android](../android/README.pt.md) ou [Web](../web/README.pt.md).

## Ports verificados

| Jogo (plataforma original) | Projeto | Dados do jogo indicados pelo projeto |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-PC-Port](https://github.com/flyngmt/ACGC-PC-Port) | Imagem USA GAFE01 Rev 0: `.iso`, `.gcm` ou `.ciso`. |
| Crash Team Racing (PlayStation) | [CTR Native](https://github.com/CTR-tools/ctr-native) | BIN bruto retail NTSC-U PSX de uma faixa, MODE2/2352; não funciona com ISO convertido para 2048 bytes. Assets extraídos são opcionais para desenvolvimento/modding. |
| 3 on 3 NHL Arcade (Xbox 360) | [3on3NHL-recomp](https://github.com/Wndwsqrrl/3on3NHL-recomp) | Pacote próprio de Xbox Live Arcade, Title ID `58410975`; não exige ISO. |
| Call of Duty: Finest Hour (Xbox) | [FinestHourRemastered](https://github.com/crazyriddler/FinestHourRemastered) | Imagem compatível de Xbox: `.iso`, imagem Redump completa ou XISO. |
| Glover (Nintendo 64) | [Glover-R](https://github.com/ThatGuyMcd/Glover-R) | ROM USA de Nintendo 64; aceita `.z64`, `.n64` e `.v64`. |
| Go! Go! Ackman (SNES) | [gogoackman1recomp](https://github.com/catmidori/gogoackman1recomp) | ROM/dump de SNES; formato exato não especificado. |
| Kameo: Elements of Power (Xbox 360) | [KameoRePowered](https://github.com/MaxDeadBear/KameoRePowered) | ISO própria de Xbox 360 (`kameo.iso`). |
| Lost Odyssey (Xbox 360) | [LostOdysseyRecomp](https://github.com/faligame/lost-odyssey-hd-remaster) | Quatro discos; aceita pastas extraídas, imagens ISO ou dados Games on Demand. O disco 1 é necessário para iniciar. |
| Naruto: The Broken Bond (Xbox 360) | [Naruto-The-Broken-Bond-PC-Port](https://github.com/Auremana666/Naruto-The-Broken-Bond-PC-Port) | ISO própria de Xbox 360. O README menciona um executável Windows; o funcionamento não foi testado independentemente. |
| Pandora's Tower (Wii) | [pandora-tower-pc](https://github.com/RecompPort/pandora-tower-pc) | ISO própria de Wii; a ficha PortIntegration informa que a recompilação ocorre durante a instalação. |
| Ridge Racer V (PlayStation 2) | [Fukami](https://github.com/danisandoval/fukami) | Dump próprio da versão USA para PS2 (SLUS-20002); extensão não especificada. |
| Scooby-Doo! Night of 100 Frights (GameCube) | [Scooby-Doo-Refrightened](https://github.com/josiahg2502-glitch/Scooby-Doo-Refrightened) | ISO USA v1.01 de GameCube (GIHE78, revisão 1). |
| Sonic Mania (assets oficiais) | [Sonic-Mania-Decompilation](https://github.com/RSDKModding/Sonic-Mania-Decompilation) | Requer assets de uma edição oficial compatível; não exige ISO/ROM. |
| Sonic the Hedgehog 1 & 2 (2013) | [RSDKv4-Decompilation](https://github.com/RSDKModding/RSDKv4-Decompilation) | Requer assets de uma edição oficial compatível (Steam, Epic ou Nintendo Switch); não exige ISO/ROM. |
| Sonic the Hedgehog CD (2011) | [RSDKv3-Decompilation](https://github.com/RSDKModding/RSDKv3-Decompilation) | Requer assets de uma edição oficial compatível; não exige ISO/ROM. |
| Super Paper Mario (Wii) | [NewSuperPaperBros](https://github.com/josiahg2502-glitch/NewSuperPaperBros) | Dump/imagem própria do disco de Wii; formato exato não especificado. |

Consulte os READMEs originais para requisitos, licenças, estado e releases. Veja também [requisitos de dados dos jogos](../game-data/README.pt.md) e o [catálogo de origem do PortsDR](../ports/README.pt.md).
