# Ports PC

Projets dont la compatibilité ou la version PC est confirmée par le README ou la documentation du dépôt. Un projet multiplateforme peut également figurer dans les catégories [Android](../android/README.fr.md) ou [Web](../web/README.fr.md).

## Ports vérifiés

| Jeu (plateforme d'origine) | Projet | Données de jeu indiquées par le projet |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-PC-Port](https://github.com/flyngmt/ACGC-PC-Port) | Image USA GAFE01 Rev 0 : `.iso`, `.gcm` ou `.ciso`. |
| Crash Team Racing (PlayStation) | [CTR Native](https://github.com/CTR-tools/ctr-native) | BIN brut retail NTSC-U PSX d'une piste, MODE2/2352 ; un ISO converti en secteurs de 2048 octets ne fonctionne pas. Les ressources extraites sont facultatives pour le développement/modding. |
| 3 on 3 NHL Arcade (Xbox 360) | [3on3NHL-recomp](https://github.com/Wndwsqrrl/3on3NHL-recomp) | Paquet Xbox Live Arcade obtenu légalement, Title ID `58410975` ; aucune ISO requise. |
| Call of Duty: Finest Hour (Xbox) | [FinestHourRemastered](https://github.com/crazyriddler/FinestHourRemastered) | Image Xbox compatible : `.iso`, image Redump complète ou XISO. |
| Glover (Nintendo 64) | [Glover-R](https://github.com/ThatGuyMcd/Glover-R) | ROM USA Nintendo 64 ; formats `.z64`, `.n64` et `.v64` acceptés. |
| Go! Go! Ackman (SNES) | [gogoackman1recomp](https://github.com/catmidori/gogoackman1recomp) | ROM/dump SNES ; format exact non précisé. |
| Kameo: Elements of Power (Xbox 360) | [KameoRePowered](https://github.com/MaxDeadBear/KameoRePowered) | ISO Xbox 360 obtenue légalement (`kameo.iso`). |
| Lost Odyssey (Xbox 360) | [LostOdysseyRecomp](https://github.com/faligame/lost-odyssey-hd-remaster) | Quatre disques ; dossiers extraits, images ISO ou données Games on Demand acceptés. Le disque 1 est nécessaire au démarrage. |
| Naruto: The Broken Bond (Xbox 360) | [Naruto-The-Broken-Bond-PC-Port](https://github.com/Auremana666/Naruto-The-Broken-Bond-PC-Port) | ISO Xbox 360 obtenue légalement. Le README mentionne un exécutable Windows ; son fonctionnement n'a pas été testé indépendamment. |
| Pandora's Tower (Wii) | [pandora-tower-pc](https://github.com/RecompPort/pandora-tower-pc) | ISO Wii obtenue légalement ; PortIntegration indique que la recompilation a lieu pendant l'installation. |
| Ridge Racer V (PlayStation 2) | [Fukami](https://github.com/danisandoval/fukami) | Dump de la version USA PS2 (SLUS-20002) ; extension non précisée. |
| Scooby-Doo! Night of 100 Frights (GameCube) | [Scooby-Doo-Refrightened](https://github.com/josiahg2502-glitch/Scooby-Doo-Refrightened) | ISO USA GameCube v1.01 (GIHE78, révision 1). |
| Sonic Mania (assets officiels) | [Sonic-Mania-Decompilation](https://github.com/RSDKModding/Sonic-Mania-Decompilation) | Nécessite les assets d'une version officielle compatible ; aucune ISO/ROM requise. |
| Sonic the Hedgehog 1 & 2 (2013) | [RSDKv4-Decompilation](https://github.com/RSDKModding/RSDKv4-Decompilation) | Nécessite les assets d'une version officielle compatible (Steam, Epic ou Nintendo Switch) ; aucune ISO/ROM requise. |
| Sonic the Hedgehog CD (2011) | [RSDKv3-Decompilation](https://github.com/RSDKModding/RSDKv3-Decompilation) | Nécessite les assets d'une version officielle compatible ; aucune ISO/ROM requise. |
| Super Paper Mario (Wii) | [NewSuperPaperBros](https://github.com/josiahg2502-glitch/NewSuperPaperBros) | Dump/image d'un disque Wii obtenu légalement ; format exact non précisé. |

Consultez les README d'origine pour les prérequis, licences, état et versions. Voir aussi les [besoins en données de jeu](../game-data/README.fr.md) et le [catalogue source PortsDR](../ports/README.fr.md).
