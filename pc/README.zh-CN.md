# PC 移植项目

此处收录的项目均由仓库 README 或文档确认支持 PC 或提供 PC 版本。支持多个平台的项目也可能出现在 [Android](../android/README.zh-CN.md) 或 [Web](../web/README.zh-CN.md) 分类中。

[Español](README.md) · [English](README.en.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · [Français](README.fr.md)

## 已核实的移植项目

| 游戏（原始平台） | 项目 | 项目注明的游戏数据 |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-PC-Port](https://github.com/flyngmt/ACGC-PC-Port) | USA GAFE01 Rev 0 镜像：`.iso`、`.gcm` 或 `.ciso`。 |
| Crash Team Racing (PlayStation) | [CTR Native](https://github.com/CTR-tools/ctr-native) | 零售版 NTSC-U 单轨 PSX 原始 BIN，MODE2/2352；2048 字节扇区的转换 ISO 无法使用。提取的资源仅在开发/修改时可选。 |
| 3 on 3 NHL Arcade (Xbox 360) | [3on3NHL-recomp](https://github.com/Wndwsqrrl/3on3NHL-recomp) | 自有 Xbox Live Arcade 游戏包，Title ID `58410975`；无需 ISO。 |
| Call of Duty: Finest Hour (Xbox) | [FinestHourRemastered](https://github.com/crazyriddler/FinestHourRemastered) | 兼容的 Xbox 光盘镜像：`.iso`、完整 Redump 镜像或 XISO。 |
| Glover (Nintendo 64) | [Glover-R](https://github.com/ThatGuyMcd/Glover-R) | USA 版 Nintendo 64 ROM；支持 `.z64`、`.n64` 和 `.v64`。 |
| Go! Go! Ackman (SNES) | [gogoackman1recomp](https://github.com/catmidori/gogoackman1recomp) | SNES ROM/转储；未注明具体格式。 |
| Kameo: Elements of Power (Xbox 360) | [KameoRePowered](https://github.com/MaxDeadBear/KameoRePowered) | 自有 Xbox 360 ISO（`kameo.iso`）。 |
| Lost Odyssey (Xbox 360) | [LostOdysseyRecomp](https://github.com/faligame/lost-odyssey-hd-remaster) | 共四张光盘；支持解压文件夹、ISO 镜像或 Games on Demand 数据。启动需要第 1 张光盘。 |
| Naruto: The Broken Bond (Xbox 360) | [Naruto-The-Broken-Bond-PC-Port](https://github.com/Auremana666/Naruto-The-Broken-Bond-PC-Port) | 自有 Xbox 360 ISO。README 提及 Windows 可执行文件；尚未独立测试其运行情况。 |
| Pandora's Tower (Wii) | [pandora-tower-pc](https://github.com/RecompPort/pandora-tower-pc) | 自有 Wii ISO；PortIntegration 页面说明安装时会执行重新编译。 |
| Ridge Racer V (PlayStation 2) | [Fukami](https://github.com/danisandoval/fukami) | USA 版 PS2 游戏转储（SLUS-20002）；未注明文件扩展名。 |
| Scooby-Doo! Night of 100 Frights (GameCube) | [Scooby-Doo-Refrightened](https://github.com/josiahg2502-glitch/Scooby-Doo-Refrightened) | USA 版 GameCube v1.01 ISO（GIHE78，修订版 1）。 |
| Sonic Mania（官方资源） | [Sonic-Mania-Decompilation](https://github.com/RSDKModding/Sonic-Mania-Decompilation) | 需要兼容官方版本的游戏资源；不需要 ISO/ROM。 |
| Sonic the Hedgehog 1 & 2 (2013) | [RSDKv4-Decompilation](https://github.com/RSDKModding/RSDKv4-Decompilation) | 需要兼容官方版本（Steam、Epic 或 Nintendo Switch）的游戏资源；不需要 ISO/ROM。 |
| Sonic the Hedgehog CD (2011) | [RSDKv3-Decompilation](https://github.com/RSDKModding/RSDKv3-Decompilation) | 需要兼容官方版本的游戏资源；不需要 ISO/ROM。 |
| Super Paper Mario (Wii) | [NewSuperPaperBros](https://github.com/josiahg2502-glitch/NewSuperPaperBros) | 自有 Wii 光盘的转储/镜像；未注明具体格式。 |

请查阅原项目 README，了解要求、许可证、状态和发布版本。另请参阅[游戏数据要求](../game-data/README.zh-CN.md)和 [PortsDR 来源目录](../ports/README.zh-CN.md)。
