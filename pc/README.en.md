# PC ports

Projects with PC compatibility or a PC version confirmed by the repository README or documentation. A multi-platform project may also appear under [Android](../android/README.en.md) or [Web](../web/README.en.md).

## Verified ports

| Game (original platform) | Project | Game data stated by the project |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-PC-Port](https://github.com/flyngmt/ACGC-PC-Port) | USA GAFE01 Rev 0 image: `.iso`, `.gcm`, or `.ciso`. |
| Crash Team Racing (PlayStation) | [CTR Native](https://github.com/CTR-tools/ctr-native) | Retail NTSC-U single-track PSX raw BIN, MODE2/2352; a cooked 2048-byte ISO will not work. Extracted assets are optional for development/modding. |
| 3 on 3 NHL Arcade (Xbox 360) | [3on3NHL-recomp](https://github.com/Wndwsqrrl/3on3NHL-recomp) | A legally obtained Xbox Live Arcade package, Title ID `58410975`; no ISO required. |
| Call of Duty: Finest Hour (Xbox) | [FinestHourRemastered](https://github.com/crazyriddler/FinestHourRemastered) | Compatible Xbox disc image: `.iso`, full Redump image, or XISO. |
| Glover (Nintendo 64) | [Glover-R](https://github.com/ThatGuyMcd/Glover-R) | USA Nintendo 64 ROM; `.z64`, `.n64`, and `.v64` are supported. |
| Go! Go! Ackman (SNES) | [gogoackman1recomp](https://github.com/catmidori/gogoackman1recomp) | SNES ROM/dump; exact format is not specified. |
| Kameo: Elements of Power (Xbox 360) | [KameoRePowered](https://github.com/MaxDeadBear/KameoRePowered) | Legally obtained Xbox 360 ISO (`kameo.iso`). |
| Lost Odyssey (Xbox 360) | [LostOdysseyRecomp](https://github.com/faligame/lost-odyssey-hd-remaster) | Four discs; extracted folders, ISO images, or Games on Demand data are supported. Disc 1 is required to start. |
| Naruto: The Broken Bond (Xbox 360) | [Naruto-The-Broken-Bond-PC-Port](https://github.com/Auremana666/Naruto-The-Broken-Bond-PC-Port) | Legally obtained Xbox 360 ISO. The README mentions a Windows executable; operation was not independently tested. |
| Pandora's Tower (Wii) | [pandora-tower-pc](https://github.com/RecompPort/pandora-tower-pc) | Legally obtained Wii ISO; PortIntegration says recompilation occurs during installation. |
| Ridge Racer V (PlayStation 2) | [Fukami](https://github.com/danisandoval/fukami) | Dump of the USA PS2 release (SLUS-20002); file extension is unspecified. |
| Scooby-Doo! Night of 100 Frights (GameCube) | [Scooby-Doo-Refrightened](https://github.com/josiahg2502-glitch/Scooby-Doo-Refrightened) | USA GameCube v1.01 ISO (GIHE78, revision 1). |
| Sonic Mania (official assets) | [Sonic-Mania-Decompilation](https://github.com/RSDKModding/Sonic-Mania-Decompilation) | Requires assets from a supported official release; no ISO/ROM required. |
| Sonic the Hedgehog 1 & 2 (2013) | [RSDKv4-Decompilation](https://github.com/RSDKModding/RSDKv4-Decompilation) | Requires assets from a supported official release (Steam, Epic, or Nintendo Switch); no ISO/ROM required. |
| Sonic the Hedgehog CD (2011) | [RSDKv3-Decompilation](https://github.com/RSDKModding/RSDKv3-Decompilation) | Requires assets from a supported official release; no ISO/ROM required. |
| Super Paper Mario (Wii) | [NewSuperPaperBros](https://github.com/josiahg2502-glitch/NewSuperPaperBros) | Dump/image of a legally obtained Wii disc; exact format is unspecified. |

See the original project READMEs for requirements, licenses, status, and releases. Also see [game data requirements](../game-data/README.en.md) and the [PortsDR source catalog](../ports/README.en.md).
