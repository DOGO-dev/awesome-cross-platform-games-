# Ports para PC

[Español](README.md) · [English](README.en.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · [Français](README.fr.md)

Proyectos cuya compatibilidad o versión para PC está confirmada por el README o la documentación del repositorio. Un proyecto multiplataforma puede figurar también en [Android](../android/README.md) o [Web](../web/README.md).

## Ports verificados

| Juego (plataforma original) | Proyecto | Datos del juego indicados por el proyecto |
|---|---|---|
| Animal Crossing (GameCube) | [ACGC-PC-Port](https://github.com/flyngmt/ACGC-PC-Port) | Imagen USA GAFE01 Rev 0: `.iso`, `.gcm` o `.ciso`. |
| Crash Team Racing (PlayStation) | [CTR Native](https://github.com/CTR-tools/ctr-native) | BIN crudo retail NTSC-U PSX de una pista, MODE2/2352; no sirve un ISO cocido de 2048 bytes. Assets extraídos opcionales para desarrollo/modding. |
| 3 on 3 NHL Arcade (Xbox 360) | [3on3NHL-recomp](https://github.com/Wndwsqrrl/3on3NHL-recomp) | Paquete Xbox Live Arcade propio, Title ID `58410975`; no requiere una ISO. |
| Call of Duty: Finest Hour (Xbox) | [FinestHourRemastered](https://github.com/crazyriddler/FinestHourRemastered) | Imagen compatible de Xbox: `.iso`, imagen Redump completa o XISO. |
| Glover (Nintendo 64) | [Glover-R](https://github.com/ThatGuyMcd/Glover-R) | ROM USA de Nintendo 64; admite `.z64`, `.n64` y `.v64`. |
| Go! Go! Ackman (SNES) | [gogoackman1recomp](https://github.com/catmidori/gogoackman1recomp) | ROM/dump de SNES; el formato exacto no está especificado. |
| Kameo: Elements of Power (Xbox 360) | [KameoRePowered](https://github.com/MaxDeadBear/KameoRePowered) | ISO propia de Xbox 360 (`kameo.iso`). |
| Lost Odyssey (Xbox 360) | [LostOdysseyRecomp](https://github.com/faligame/lost-odyssey-hd-remaster) | Cuatro discos; admite carpetas extraídas, ISO o datos Games on Demand. El disco 1 es necesario para iniciar. |
| Naruto: The Broken Bond (Xbox 360) | [Naruto-The-Broken-Bond-PC-Port](https://github.com/Auremana666/Naruto-The-Broken-Bond-PC-Port) | ISO propia de Xbox 360. El README menciona un ejecutable de Windows; no se verificó el funcionamiento de forma independiente. |
| Pandora's Tower (Wii) | [pandora-tower-pc](https://github.com/RecompPort/pandora-tower-pc) | ISO propia de Wii; la ficha de PortIntegration indica que la recompilación se genera durante la instalación. |
| Ridge Racer V (PlayStation 2) | [Fukami](https://github.com/danisandoval/fukami) | Volcado propio de la versión USA para PS2 (SLUS-20002); no se especifica la extensión. |
| Scooby-Doo! Night of 100 Frights (GameCube) | [Scooby-Doo-Refrightened](https://github.com/josiahg2502-glitch/Scooby-Doo-Refrightened) | ISO USA v1.01 de GameCube (GIHE78, revisión 1). |
| Sonic Mania (assets oficiales) | [Sonic-Mania-Decompilation](https://github.com/RSDKModding/Sonic-Mania-Decompilation) | Requiere assets de una edición oficial compatible; no requiere ISO/ROM. |
| Sonic the Hedgehog 1 & 2 (2013) | [RSDKv4-Decompilation](https://github.com/RSDKModding/RSDKv4-Decompilation) | Requiere los assets de una edición oficial compatible (Steam, Epic o Nintendo Switch); no requiere ISO/ROM. |
| Sonic the Hedgehog CD (2011) | [RSDKv3-Decompilation](https://github.com/RSDKModding/RSDKv3-Decompilation) | Requiere los assets de una edición oficial compatible; no requiere ISO/ROM. |
| Super Paper Mario (Wii) | [NewSuperPaperBros](https://github.com/josiahg2502-glitch/NewSuperPaperBros) | Dump/imagen propia del disco de Wii; el formato exacto no está especificado. |

Consulta los README originales para requisitos, licencias, estado y releases. Ver también [Requisitos de juego](../game-data/README.md) y el [catálogo fuente de PortsDR](../ports/portsdr-projects.md).
