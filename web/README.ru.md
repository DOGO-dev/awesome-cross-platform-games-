# Игры и порты для Веб

В этом разделе собраны ссылки на игры и порты, запускаемые в браузере, отобранные из списка, предоставленного владельцем репозитория. Исключены записи с пометками fangame, ROM hack, сборник/компендиум, программное обеспечение, настольная игра, очевидная фанатская работа или нераспознанные теги.

Исходный список **не подтверждает**, что для каждой веб-версии получено разрешение правообладателя. Перед использованием проверьте связанный проект и его правовой статус. Репозиторий не размещает файлы игр.

Полный список из 205 ссылок размещён в [каталоге на испанском](README.md), чтобы не дублировать записи в переводах. В него входят 156 записей исходного списка и ещё 49 source-портов/реализаций.
