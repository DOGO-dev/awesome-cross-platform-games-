# Web games and ports

This section links to browser-playable games and ports selected from the list shared by the repository owner. Entries marked as fangames, ROM hacks, compilations/compendiums, software, board games, identifiable fan works, or records with unidentified tags were excluded.

The source list does **not** verify whether every web release is authorized by the rights holder. Check each linked project and its legal status before using it. This repository does not host game files.

The complete, 205-link list is maintained in the [Spanish catalog](README.md) to avoid duplicating records across translations. It includes 156 entries from the original list and 49 additional source ports/reimplementations.
