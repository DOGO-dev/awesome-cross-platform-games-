# Jeux et ports Web

Cette section rassemble des liens vers des jeux et ports jouables dans un navigateur, sélectionnés à partir de la liste fournie par le propriétaire du dépôt. Les entrées signalées comme fangame, ROM hack, compilation/compendium, logiciel, jeu de société, fanwork identifiable ou dotées de tags non identifiés ont été exclues.

La liste source ne **vérifie pas** que chaque version Web est autorisée par les ayants droit. Vérifiez le projet lié et son statut juridique avant toute utilisation. Ce dépôt n'héberge pas de fichiers de jeu.

La liste complète de 205 liens est conservée dans le [catalogue en espagnol](README.md) afin d'éviter les doublons dans les traductions. Elle comprend 156 entrées de la liste initiale et 49 ports source/réimplémentations supplémentaires.
