# Web 游戏与移植项目

本节收录仓库所有者提供的列表中可在浏览器运行的游戏和移植项目链接。已排除标记为同人游戏、ROM hack、合集/汇编、软件、桌游、可识别的同人作品或含有未知标签的条目。

来源列表**未核实**每个 Web 版本是否获得版权所有者授权。使用前请检查链接项目及其法律状态。本仓库不托管游戏文件。

为避免不同语言重复维护条目，完整的 205 个链接统一保存在[西班牙语目录](README.md)中，其中包括原列表的 156 项和新增的 49 个源码移植/重新实现项目。
