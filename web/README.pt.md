# Jogos e ports para Web

Esta seção reúne links para jogos e ports executados no navegador, selecionados a partir da lista compartilhada pelo proprietário do repositório. Foram excluídas entradas marcadas como fangame, ROM hack, compilação/compêndio, software, jogo de tabuleiro, fanworks identificáveis ou registros com tags não identificadas.

A lista de origem **não verifica** se cada versão Web tem autorização dos detentores dos direitos. Confira o projeto indicado e sua situação legal antes de usar. Este repositório não hospeda arquivos de jogos.

A lista completa, com 205 links, é mantida no [catálogo em espanhol](README.md) para evitar duplicação de registros entre traduções. Ela inclui 156 entradas da lista original e mais 49 ports de código-fonte/reimplementações.
