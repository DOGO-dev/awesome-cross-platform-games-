## Просмотр проектов

На [главной странице на испанском](README.md) размещены проверенные порты для ПК и Android, отфильтрованный список веб-игр, требования к данным по консолям и полный каталог PortsDR.

## Правила каталога

- Целевая платформа указывается, только если она подтверждена в README или документации проекта. Проект для нескольких платформ может присутствовать в нескольких разделах.
- Исходная платформа и название проекта сохраняются как метаданные; по ним нельзя угадывать целевую платформу или формат данных.
- Ссылки ведут на оригинальные проекты и документацию. Репозиторий не распространяет игры, образы дисков, ROM, BIOS, ключи и защищённые ресурсы.
- Проверяйте документацию авторов: требования, лицензию, статус и необходимые файлы.
