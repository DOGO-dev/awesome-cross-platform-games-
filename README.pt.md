## Critérios do catálogo

- Classificamos pela **plataforma de destino** somente quando ela é confirmada no README ou na documentação do projeto. Um projeto compatível com vários destinos pode aparecer em mais de uma seção.
- A plataforma original e o nome do projeto são mantidos como metadados; não são usados para adivinhar o destino nem o formato de dados necessário.
- Os links apontam para os projetos e a documentação originais. Este repositório não distribui jogos, imagens de disco, ROMs, BIOS, chaves ou assets protegidos.
- Consulte a documentação dos autores para requisitos, licença, estado e arquivos necessários.
