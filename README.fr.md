## Principes du catalogue

- Le classement par **plateforme cible** n'est effectué que si le README ou la documentation du projet le confirme. Un projet compatible avec plusieurs plateformes peut figurer dans plusieurs sections.
- La plateforme d'origine et le nom du projet sont conservés comme métadonnées ; ils ne servent pas à deviner la cible ni le format de données requis.
- Les liens renvoient aux projets et à leur documentation d'origine. Ce dépôt ne distribue pas de jeux, images disque, ROM, BIOS, clés ni ressources protégées.
- Consultez la documentation des auteurs pour connaître les prérequis, la licence, l'état du projet et les fichiers nécessaires.
